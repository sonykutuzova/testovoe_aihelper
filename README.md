# Генерация описаний товаров

API принимает данные прибора в JSON и через OpenAI формирует карточку: SEO-заголовок, описание, характеристики, поисковые запросы и текст для менеджера.

## Запуск

```bash
git clone https://github.com/sonykutuzova/testovoe_aihelper.git
cd testovoe_aihelper
export OPENAI_API_KEY="ваш_ключ"
python3 -m aihelper
```

## Запрос

```bash
curl http://127.0.0.1:8000/generate \
  -H 'Content-Type: application/json' \
  --data-binary @examples/manometer.json
```

Примеры входных данных лежат в `examples`, карточек в `examples/results`.

## Решение

Используется `gpt-4.1-mini`. Промпт в `aihelper/prompts.py` задаёт формат ответа и запрещает добавлять характеристики, которых нет во входных данных. Код проверяет длину текста и новые числовые значения. Характеристики копируются из JSON, пропуски отмечаются как «данных нет».

Текст всё равно нужно сверить с паспортом. Следующим шагом можно добавить извлечение характеристик из него.

В задании был только манометр, поэтому второй товар учебный. Примеры ответов подготовлены вручную. Реальный API пока не проверен, тесты используют подставные ответы.
