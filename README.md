# AI-помощник для товарных описаний

API на Python для подготовки карточек контрольно-измерительных приборов. Принимает JSON с данными товара и возвращает SEO-заголовок, описание, характеристики, поисковые запросы и блок для менеджера. Используется OpenAI Responses API.

## Запуск

Нужен Python 3.11 или новее. Дополнительных зависимостей нет.

```bash
git clone https://github.com/sonykutuzova/testovoe_aihelper.git
cd testovoe_aihelper
export OPENAI_API_KEY="ваш_ключ"
export OPENAI_MODEL="gpt-4.1-mini"
python3 -m aihelper
```

Ключ берётся из переменной окружения. Файлы `.env` автоматически не загружаются. При необходимости порт можно изменить: `python3 -m aihelper --port 8001`.

## Использование

```bash
curl http://127.0.0.1:8000/health

curl http://127.0.0.1:8000/generate \
  -H 'Content-Type: application/json' \
  --data-binary @examples/manometer.json
```

На входе обязательное поле `name`. Поля `manufacturer`, `specs` и `description` можно оставить пустыми. Значения в `specs` передаются строками с единицами измерения, например `"питание": "24 В"`.

В ответе возвращаются `seo_title`, `seo_description`, `characteristics`, `search_queries`, `commercial`, `missing_fields` и `clarifications`. Недостающие характеристики отмечаются как «данных нет». Максимальный размер запроса 64 КБ.

Некорректный JSON возвращает 400, отсутствие названия или ошибка проверки генерации 422, неверный Content-Type 415, превышение размера 413. При ошибке API возвращается понятное сообщение без ключа и внутренних данных провайдера.

## Как работает

Промпт находится в `aihelper/prompts.py`. В нём заданы формат карточки, ограничения длины и запрет добавлять сведения вне исходных данных. Инструкции внутри описания товара считаются данными, а не командами.

После ответа проверяются структура, заголовок до 70 символов, описание от 800 до 1200 символов, от 3 до 5 разных поисковых запросов и отсутствие новых чисел и технических обозначений. При нарушении выполняется одна повторная генерация. Таблица характеристик собирается напрямую из входного JSON.

## Примеры и тесты

В `examples` находятся входные данные, в `examples/results` примеры карточек. Манометр взят из задания. Второй товар учебный, поскольку его данных в задании не было. Сохранённые карточки подготовлены вручную как примеры формата, а не получены через API.

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют валидацию, неполные данные, ошибки API и HTTP-запросы. Ответы модели в тестах подменяются. Реальный вызов OpenAI без API-ключа не проверялся.

## Ограничения

Проверка чисел не гарантирует смысловую достоверность текста. Перед публикацией нужно сверить карточку с паспортом. Данные из свободного описания не переносятся автоматически в таблицу. Поисковые запросы не проверяются на частотность.

В дальнейшем можно добавить извлечение характеристик из паспортов с цитатами и проверку противоречий между источниками. Сервер рассчитан на локальный запуск.
